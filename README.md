# Dr. Jyoti Rajaram — Professional Portfolio

Responsive single-page static website built with semantic HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` directly in a modern browser, or use a local static server from this folder, for example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` — page content and sections
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation, reveal animations, and email-based enquiry form
- `assets/` — cropped portrait and conference photo supplied for the portfolio preview

## Contact form behavior

The form validates required fields and opens the visitor's email application with a pre-filled message addressed to `jyotirajaram0310@gmail.com`. It does not store submissions or confirm appointments. A backend or form provider is required to receive submissions without relying on the visitor's email application.
